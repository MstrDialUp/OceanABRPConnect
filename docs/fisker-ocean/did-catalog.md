# Fisker Ocean DID catalog

Generated by `tools/analyze/catalog.py` from a discovery sweep and recorded sessions (Ocean OS 2.2.3, 2026-09-28/29). Service `0x22` ReadDataByIdentifier, 11-bit CAN, 500 kbps. Ranges swept on every module: `2000-20FF,2100-21FF,3400-34FF,D000-D1FF,EF00-EFFF,F100-F1FF,F400-F4FF,FD00-FDFF`. See [README.md](README.md) for how to read these and what's decoded.

Columns: **len** is the data length in bytes after the DID echo. **live** is yes if the value changed during the recordings, no if it stayed constant, and blank if it wasn't recorded. Per-car values (VIN, serial numbers) are withheld.

272 DIDs returned data; 15 exist but refused (NRC shown).
