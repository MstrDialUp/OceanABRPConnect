# Recorded sessions

Commit session files exported from the app's Sessions tab here, unchanged. Each file is JSONL: a `header` line, then `did` / `nrc` / `gps` / `atrv` / `event` lines, then a `footer` with the stop checklist. All values are metric and `t` is epoch milliseconds. The full format is in PLAN.md §4.3 and §6.2.

Session files include GPS tracks. Check you're comfortable with the repository's visibility before committing them.
